INGENIO MECÁNICO - SITIO WEB
============================

1. Abre index.html para ver la página.
2. Reemplaza:
   - assets/felipe.svg por una foto real de Felipe Gómez (puedes llamarla felipe.jpg y cambiar el src en index.html).
   - assets/taller.svg y assets/trabajo.svg por fotos reales.
   - assets/logo.svg por el logo final si decides usar otra versión.
3. Para videos de YouTube, reemplaza cada bloque .video-placeholder por un iframe de YouTube.
4. La dirección del taller y correo aún no fueron suministrados; pueden agregarse en la sección Contacto.
5. El botón de WhatsApp ya está configurado con 316 672 2371.
6. Para publicar: puedes subir esta carpeta a un hosting, GitHub Pages, Netlify o similar.

IMPORTANTE:
La información comercial (garantías, años de experiencia, marcas atendidas, etc.) debe ajustarse a los datos reales del taller antes de publicar.
